斜め撮り → 正面化

画像をアップロード
使い方:
  1. 画面幅900px以上では、左に元画像と操作パネル、右に補正結果が並びます（右はスクロールしても見えます）。画像をアップロードすると、四隅付近に4点が自動配置されます（点1=左上 → 2=右上 → 3=右下 → 4=左下 の時計回り）。
  2. 各点をドラッグして、補正したい四角形の角に大まかに合わせます。点は掴んだ位置からずれずに動きます。
  3. 点を選ぶとルーペ（拡大表示）が出ます。ドラッグ中は指で隠れないよう、点と反対側の隅に表示されます。倍率は 2x / 4x / 8x で切り替えられます。
  4. 元画像の下の「点1〜点4」で点を選び、十字ボタンで微調整します。移動量は 1px / 5px / 20px（元画像のピクセル単位）。ボタン長押しで連続移動します。キーボードの矢印キーでも動かせます（Shift+矢印で10px）。
  5. 点のない場所をタップ/クリック、または Esc キーで選択を解除するとルーペが消えます。
  6. 「補正実行」で結果を更新します（またはリアルタイムプレビューをオン）。プレビューは縮小して計算し、「補正実行」と「結果をダウンロード」はフル解像度で計算します。
  7. Ctrl+Z または「元に戻す」で取り消せます（ドラッグは1回ごと、連続した微調整はひとまとまりで取り消し）。
点を動かすたびに補正結果を自動更新します（縮小プレビュー）
