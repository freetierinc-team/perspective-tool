# 斜め撮り → 正面化ツール

斜めから撮影した写真（スロット台の液晶など）の4隅を指定し、射影変換で正面から見た長方形の画像に補正するツールです。
`index.html` 1ファイルで動作し、外部ライブラリやネット接続は不要です。画像はブラウザ内で処理され、どこにも送信されません。

## 起動方法

`index.html` をブラウザ（Chrome / Edge / Safari / Firefox）で開きます。スマホでも使えます。

## 基本の流れ

1. 「画像をアップロード」で写真を選ぶと、四隅付近に4つの点が自動で置かれます。
   - 点1=左上、点2=右上、点3=右下、点4=左下（時計回り）
2. 各点をドラッグして、液晶の角に大まかに合わせます。
3. ルーペと十字ボタンで角にぴったり合わせます（下記）。
4. 「補正実行」で補正結果を表示します。
5. 「結果をダウンロード」で PNG 画像（corrected_image.png）を保存します。

## 画面構成

画面幅900px以上（PC）は2カラム、900px未満は縦並びです。

- 左カラム: 元画像（高さは画面の約75%まで）、その下に操作パネル（点の選択ボタン、十字ボタン、移動量、ルーペ倍率）、補正実行 / 元に戻す / 結果をダウンロード、ステータス
- 右カラム: 補正結果（スクロールしても画面内に追従）
- 900px未満: 元画像 → 操作パネル → ボタン → 補正結果の順に縦に並びます

ウィンドウサイズやスマホの向きを変えても、点の位置は元画像上の同じ場所に保たれます。

## 操作方法

### 点の移動（ドラッグ）

- マウスでもタッチでもドラッグできます。タッチ時は点の当たり判定が大きくなります。
- 点は掴んだ位置からずれずに動くので、指の中心に飛ぶことはありません。
- 点のない場所をタップ/クリックすると選択を解除します。何も選択していないときは何も起きません（誤操作防止）。

### ルーペ（拡大表示）

- 点を選択している間、元画像の上に円形の拡大ビューが表示されます。
- 拡大ビューは元画像の高解像度ピクセルから描画され、中央の十字線の中心が点の位置です。
- 指やカーソルで隠れないよう、点と反対側の隅（点が左側なら右上、右側なら左上）に表示されます。他の点を覆う数が最も少ない隅が優先されます。
- 倍率は「ルーペ倍率」の 2x / 4x / 8x で切り替えます（表示に対する倍率）。8x など高倍率では画素の境界がくっきり表示されます。
- ルーペに隠れた点を動かしたいときは、「点1〜点4」ボタンでその点を選ぶとルーペが移動します。

### 十字ボタンでの微調整

- 「点1〜点4」ボタンで動かす点を選びます（選択中は黒く表示。もう一度押すと選択解除）。ボタンには元画像ピクセル単位の座標が表示されます。
- ↑ ← → ↓ ボタンで、選択中の点を移動します。
- 「移動量」で 1px / 5px / 20px（元画像のピクセル単位）を切り替えます。
- ボタンを長押しすると連続で移動します。

### キーボード

| キー | 動作 |
| --- | --- |
| 矢印キー | 選択中の点を 1px 移動 |
| Shift + 矢印キー | 選択中の点を 10px 移動 |
| Esc | 選択解除 |
| Ctrl + Z（Mac は Cmd + Z） | 元に戻す |

文字入力欄などにフォーカスがあるときは、矢印キーでの移動は行いません。

### 元に戻す

- 「元に戻す」ボタンまたは Ctrl + Z で、直前の操作を取り消します。
- ドラッグは1回ごとに1つの操作として取り消します。
- 十字ボタンや矢印キーでの微調整は、続けて操作した分（操作の間隔が約0.8秒以内）をまとめて1回で取り消します。

## リアルタイムプレビュー

- オンにすると、点を動かすたびに補正結果を自動更新します。
- プレビューは処理を軽くするため、出力を長辺 約600px に縮小して計算します。
- 「補正実行」と「結果をダウンロード」は常にフル解像度で計算します。プレビュー中にダウンロードした場合も、その時点の点の位置でフル解像度の画像を作り直して保存します。
- オンの間は「補正実行」ボタンは押せません（結果は自動で更新されます）。

## 補正の仕組み

- 4点から射影変換行列を求め、補正後の各画素について元画像の対応位置をバイリニア補間で取得します。
- 出力のアスペクト比は、4点が長方形を斜めから写したものであるという前提から推定します（推定できない場合は対辺の長さの平均を使用）。
- 出力サイズは元画像の解像度に応じて自動で決まります。

## 注意事項

- 元画像の上では、ページのスクロールではなく点の操作が優先されます。スマホでページをスクロールするときは、画像の外側（左右の余白や操作パネル）をスワイプしてください。
- 非常に大きな画像では、「補正実行」やダウンロードに数秒かかることがあります。
